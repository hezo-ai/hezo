# Executing Plans

Load the plan, review it critically, execute the tasks in order, and report with evidence.

## Step 1: Load and review

1. Read the entire plan before touching anything.
2. Review it critically — identify questions, gaps, or concerns.
3. If you have concerns, raise them in the task thread *before* starting. Executing a plan you doubt wastes everyone's time.
4. If not, track the plan's tasks (sub-tasks or a checklist in the thread) and begin.

## Step 2: Execute

For each task in the plan:

1. Mark it in progress.
2. Follow the steps exactly — the plan's bite-sized steps exist so nothing is skipped.
3. Run every verification the plan specifies and read the result. Don't substitute "it looks right".
4. Mark it complete only when its verification passed.

## When to stop and ask

Stop executing and ask in the task thread when:

- you hit a blocker — a missing dependency, credential, or input, a failing verification, an unclear instruction;
- the plan has a gap that prevents starting a task;
- a verification fails repeatedly.

Ask rather than guess. A run legitimately parks on a question it can't answer itself; a run that guesses produces work that has to be redone.

## When reality diverges from the plan

Plans meet reality; reality sometimes wins. When you discover the plan's approach doesn't work:

1. **Stop** — don't push through with improvisations while the thread still says you're following the plan.
2. **Say so where the plan lives** — post what you found, why the planned approach fails, and the revised approach.
3. **Revise, then continue.** An openly revised plan is progress; a silently abandoned one destroys the record everyone else relies on.

## Remember

- Review critically first — you're the last check before execution.
- Follow steps exactly; don't skip verifications.
- Stop when blocked; ask, don't guess.
- Announce plan changes in the task thread before acting on them.
- When all tasks are done, verify the whole against the original goal (not just each step) before reporting completion — with the evidence.
